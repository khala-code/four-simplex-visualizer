# Contributing

Thanks for taking an interest in improving Four Simplex.

This project is intentionally small. The goal is to keep it understandable, shareable, and useful as an introductory demo for visualizing four-factor balance inside a simplex.

## Project priorities

Contributions should support these goals:

- Keep the demo easy to understand for a general audience.
- Prefer clarity over cleverness.
- Preserve the simplex-only scope unless a change clearly improves the core experience.
- Keep diagnostic language plain and readable.

## Good contribution ideas

Examples of changes that fit the project well:

- UI polish that improves readability
- Better summary text and clearer status wording
- Axis label improvements
- Small visualization improvements
- Bug fixes in normalization, health checks, or rendering
- Accessibility improvements
- Documentation improvements

## Changes to discuss first

Please open an issue before working on larger changes such as:

- New mathematical models beyond the current simplex demo
- Signed-coordinate or external-field support
- Major UI rewrites
- Persistence, accounts, or backend features
- Large dependency additions

## Style expectations

- Keep code simple and direct.
- Use names that make the math and UI easy to follow.
- Avoid unnecessary abstraction.
- Prefer short, readable helper functions over clever compression.
- Keep user-facing text plain-language first.

## Pull requests

A good pull request should include:

- A short description of what changed
- Why the change helps the demo
- Screenshots or a short note for any UI change
- Small, focused diffs where possible

## Before submitting

Please check that:

- The app still runs cleanly
- The diagnostic output is internally consistent
- Labels and summary text still make sense to a non-technical reader
- The README stays accurate

## Scope note

Four Simplex is currently scoped as an introductory hyperplane/simplex demo. That means contributions should generally reinforce the existing teaching value instead of expanding the model too quickly.

Thanks again for helping improve it.
